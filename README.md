# Haroon Ahmed Butt — portfolio

Senior Product Designer portfolio. A study-and-rebuild of the techniques behind sashamartynchuk.com with original code, copy and assets.

**Stack:** Vite + vanilla TypeScript (multi-page) · GSAP 3 · Lenis · Three.js · Matter.js · Vercel.

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # typecheck + production build to dist/
npm run preview   # serve dist/ on :4173
```

- All copy and project data live in `src/content.ts` and are rendered into the HTML shells at build time (`src/render/html.ts`, wired by the `renderContent` plugin in `vite.config.ts`).
- Placeholder media is generated by `node scripts/gen-placeholders.mjs` into `public/media/`.
- Fonts are self-hosted in `public/fonts/` (OFL — see `LICENSES.md` there).
- `projects/spiral/` is the standalone spiral-gallery experiment (separate Vercel project); it is not part of this build.

Build stages are tracked in the "Portfolio 2026" project docs (`06-build-plan.md`).
